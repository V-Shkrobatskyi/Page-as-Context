Privacy policy for Page as Context

Last updated: 2026-10-29. Applies to version 2.1.0.

Information and local processing

Page as Context exports page context for AI conversations or notes. Capture, compression, redaction and export preparation run locally after your request. There is no capture backend, analytics, advertising SDK or LLM API integration, and no background monitoring of browsing history.

Exports may include page text, title, URL, accessible labels, semantic roles, form values and states, capture time, browser/platform/version metadata, extension version and export settings. Page data may contain personal or sensitive information. Chrome reads accessibility snapshots of the main document and eligible frames; Firefox reads HTML/ARIA semantics. Both omit password input values, including in frames.

Storage and retention

Saved settings

Remember settings saves compression, format and redaction preferences in browser-local extension storage. Save filters stores filter settings and custom text locally. Filters are not automatically synchronized or downloaded from external lists. Filter exports include custom text; review them before sharing.

Data controls and capture-site allowed/blocked lists are also stored locally. Site lists only add restrictions to organization policy, affect future captures and do not erase history. Diagnostic reports exclude these lists.

Temporary data

Captured content is processed temporarily, without a persistent page archive. Memory reclamation depends on runtime/browser cleanup. Desktop element selections end on cancellation, navigation, disconnection or after five minutes. They are not saved as site rules or history records; optional history records only the metadata described below. Accessible names may include labels outside the selected block.

Preview keeps original text and edits in tab memory, not in preview URLs. Closing or reloading loses the draft. Manual edits are not checked for sensitive data. Opening Preview does not copy anything; Copy requires your action. Filter test samples/results stay in the settings tab and are not saved.

History and diagnostics

Capture history is off by default. If enabled by you or your organization, it stores titles, URLs, browser, capture time, page/selection scope, selected-element tags, extension version and export settings, without captured contents. URL credentials are removed; exclusions and redaction apply, but titles/URLs may still be sensitive. Private/incognito tabs and Demo are excluded.

History defaults to 60 days/10 MiB, configurable to 1–365 days/1–50 MiB, with a 100,000-entry limit. Expiry runs during history access. Off stops recording; Clear history removes records unless organization policy forbids it. Administrators may lock settings; automatic retention continues. Current restrictions may remove metadata from existing records permanently. History is local, excluded from diagnostic reports and exported only when you choose copy/save, subject to organization restrictions.

The local technical journal defaults to Error. It stores technical codes, timestamps, temporary random operation IDs, durations and repeat counts, excluding page content, URLs, titles, field values, filenames, filter text and raw errors. Default limits are 1,000 events, 2 MiB and seven days; expiry runs during access. Personal Debug ends after 30 minutes, including across restarts. Administrators may lower limits or control logging. Off stops new entries; Clear journal removes retained entries unless prohibited. Automatic retention continues; recent entries can be lost on shutdown.

Diagnostic JSON contains runtime capabilities, policy status, restriction flags/counts, effective settings and journal usage, excluding source lists and filter text. Journal events are opt-in. Copy/save requires your choice and follows organization restrictions. The journal is for troubleshooting, not a browsing archive or tamper-proof audit record.

Clipboard, files and deletion

Copy writes to your clipboard; Desktop Save writes a UTF-8 file to a browser-controlled destination. Android supports Copy only. Clipboard history/synchronization, downloads, backups and destination apps may retain copies under their own settings.

Clear extension data or uninstall to remove extension-local data. Delete exported files and clipboard/history copies separately through your browser, operating system or destination app.

Sharing and external services

Optional MCP: disabled by default. New installations use Automatic connection; existing users stay Manual until switching. Choose AI Off, Read or Write for each tab; Read can be selected before a client connects. In Automatic, one-time code comparison and pairing approval authorize each client for all tabs marked Read or Write, without another shared-access opt-in. Write includes reading and supported actions, with browser approval by default. Independent clients can share multiple explicitly permitted tabs.

The helper uses local IPC and Native Messaging; the AI client may forward returned context to its model provider. Automatic access defaults to one hour of inactivity for Read and Write. Successful reads and applied actions renew only that tab; status and discovery do not. Users can choose minutes, hours, days or unlimited, subject to organization session caps. Automatic Read and Write stay with the tab across reloads and site changes, including private sites, subject to privacy filters and source policies. Navigation does not renew expiry; new tabs start Off. Transport recovery restores only authorized Read. Close/discard, browser restart, extension reload and unverified background recreation clear access. Snapshots, approvals and actions are never restored or replayed.

Off removes this tab for all approved clients; Revoke removes one client; Pause all blocks page access until Resume, without restoring Write. Stop removes grants and sharing intents. These actions cannot recall delivered data. Preferences store connection mode, trusted-client hashes/membership and pause state; protected helper files retain credentials until explicit removal. Page payloads, snapshots, receipts and entered values are not persisted in preferences or diagnostics.

Tab discovery exposes only already-authorized tabs, opaque references and window/activity hints. Titles obey data exclusions and redaction; discovery returns no URLs or catalog of unshared tabs. Firefox separately requests optional website-content, browsing-activity and personal-communication transmission consent, plus website-activity consent for Write. Browser capture permissions remain independent; declining keeps ordinary exports available.

The extension does not upload captured content, URLs, preferences, history or journal entries automatically, send them to the developer, sell data or use it for advertising. If you paste/upload an export elsewhere, that service’s policies apply.

Help, project, contact and donation links open only when chosen, without capture data attached. Linked services, email and payment providers may receive normal navigation, contact or payment information under their policies.

Support emails and GitHub issues contain information you provide and may be retained by recipients. Omit passwords, tokens and private page content. Contact the developer to request deletion of information sent directly; public GitHub content also follows GitHub’s controls and policies.

Permissions

  • Chrome debugger: temporarily reads the active page and eligible frames after an export or authorized MCP request, checks frame visibility/password input types, and performs explicitly approved MCP interactions before detaching. MCP also resolves selected/shared-tab metadata through this existing API without attaching; other targets are not exposed to clients.
  • activeTab and scripting: provide temporary page access and the on-demand Desktop element picker. Firefox also uses them for page/frame capture and approved MCP interactions through fixed isolated-world operations.
  • Firefox optional site access: Include frames from other sites is off by default. Enabling requests access to all HTTP/HTTPS sites. Access persists across tabs/restarts; switching off revokes it, including earlier individual grants. Ordinary capture requires Copy, Preview or Desktop Save; MCP capture requires a separately authorized connection. Protected frames may remain unavailable.
  • clipboardWrite: copies your requested export.
  • downloads: saves requested files on Desktop. Firefox asks for this optional permission on Save; Android never requests it.
  • nativeMessaging (optional): connects to the local helper only after MCP enablement and permission consent.
  • alarms: schedules bounded MCP retries and access expiry without capturing pages.
  • storage: saves preferences and filter settings locally.

Security and redaction

Redaction is on by default, but pattern-based filters cannot guarantee removal of all credentials or personal information. Disabling it may expose original values. Review exports before sharing. Page content is untrusted; the extension does not guarantee removal of instructions aimed at AI assistants.

Chrome Web Store Limited Use

Information obtained through browser permissions is used solely for user-requested page-context export, in compliance with the Chrome Web Store User Data Policy, including Limited Use requirements. Captured data is not transferred to the developer or third parties, used for personalized advertising, or made accessible to the developer.

Changes and contact

Data-handling changes will be reflected here with an updated date. This policy is included in the extension and project repository.

Privacy questions: copyascontext@gmail.com or the project repository. Do not share sensitive exports in public issues.
