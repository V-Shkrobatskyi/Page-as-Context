    How to use filters

    Duplicate copies a configurable built-in; turn the original off to replace it. Use a separate row for each Rule type. Automatic built-ins can only be switched on or off.

    Except for Regex, matching rules use literal text or prefixes. Separate alternatives with / (space, slash, space); commas and ordinary path slashes stay literal. Text — single literal matches the entire cell as one phrase. Automatic email, phone, card, IBAN and personal-field rules need no matching text or case settings.

    Field labels matches terms within labels and hides values and nested text, keeping labels visible. Field labels — whole words requires word boundaries. URL parameters hides query values; enter parameter names only, without ?, &, =, # or line breaks.

    Rule types and examples

    Authorization: a scheme such as Bearer / Basic, whitespace, then a credential of 8+ characters. Keeps the scheme.

    JWT: a prefix such as eyJ, then 5+ characters, followed by two dot-separated segments of 5+ characters each. Allowed: letters, digits, underscores and hyphens.

    Token formats: GitHub prefixes such as ghp_ / github_pat_ need 20+ letters, digits or underscores. AWS AKIA / ASIA needs exactly 16 uppercase letters/digits (lowercase too when case-insensitive). OpenAI sk- / sk-proj- needs 16+ letters, digits, underscores or hyphens. Use Regex presets for custom token rules.

    Assigned secrets: a label such as api_key / token, then : or = and 8+ value characters. Whitespace, &, quotes, commas or semicolons end the value. Keeps the label and separator.

    Email masking is on by default: abcdef@gmail.com → abc***@gm***.com. Each name/domain part keeps half its characters, rounded down, up to three; the final suffix stays visible. Optional Hide email addresses hides the whole address. Full hiding always overrides masking.

    Regex hides matches in text, fields, links and metadata. Insert example… provides email, token/key and order-ID presets. Enter expressions without surrounding slashes or flags; use | for alternatives. Case sensitive controls default case matching. Lookarounds/backreferences are unsupported; empty matches are ignored and [REDACTED] markers preserved.

    Credential detectors require word boundaries and check patterns, not validity. Regex presets cover common formats only; test your own samples. Limits: 256 characters per matching rule (4,096 for Regex), 131,072 total, and 1 MB per import.
